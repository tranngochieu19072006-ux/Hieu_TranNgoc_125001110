# Personal Portfolio — Dark / Neon Purple

Website portfolio cá nhân tĩnh, dùng HTML5, CSS3 và JavaScript thuần. Thiết kế theo tông đen/tím neon, có bố cục responsive, Animate.css và AOS.

## 1. Cấu trúc thư mục

```text
Portfolio_Dark_Neon_125001110/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   └── (đặt ảnh cá nhân, ảnh dự án tại đây nếu có)
├── PROMPT_LOG.md
├── TEST_CHECKLIST.md
├── GITHUB_PAGES_GUIDE.md
└── README.md
```

## 2. Chạy website trên máy

1. Giải nén ZIP.
2. Mở thư mục project bằng VS Code.
3. Mở `index.html` bằng trình duyệt; hoặc dùng extension **Live Server** trong VS Code và chọn **Open with Live Server**.
4. Các thư viện Animate.css, AOS và font Inter được tải từ CDN, vì vậy cần Internet để hiển thị đầy đủ hiệu ứng/font. Nội dung và CSS chính vẫn nằm trong source project.

## 3. Cá nhân hóa trước khi nộp

Mở `index.html`, tìm và thay:
- Tên hiển thị hiện tại là `HieuTran` / `HT`; đổi lại nếu cần.
- `your.email@example.com` bằng email thật.
- Link GitHub/LinkedIn mẫu bằng link tài khoản thật.
- Nội dung kỹ năng và 3 dự án mẫu bằng thông tin trung thực của bạn.
- MSSV hiện để `125001110`.

Không nên giữ thông tin placeholder khi nộp bài. Nếu chưa có dự án thật, hãy ghi rõ đây là bài thực hành/mẫu.

## 4. Tiêu chí đề thi đã triển khai

- **HTML5 semantic:** `header`, `nav`, `main`, `section`, `article`, `footer`.
- **CSS variables:** màu sắc, font, spacing, radius được khai báo trong `:root`.
- **Responsive:** Flexbox/Grid và media queries.
- **Animate.css:** hiệu ứng cho thành phần hero.
- **AOS:** hiệu ứng xuất hiện khi cuộn trang.
- **Hover/focus:** trạng thái cho nút, card và liên kết.
- **Tài liệu:** `PROMPT_LOG.md`, checklist và hướng dẫn GitHub Pages.

## 5. Trước khi nộp

- Hoàn thành `TEST_CHECKLIST.md`.
- Đọc và cập nhật `PROMPT_LOG.md` dựa trên đúng những gì bạn đã tự kiểm tra.
- Làm theo `GITHUB_PAGES_GUIDE.md`.
- Repository cần đặt theo định dạng đề bài `Ten_Ho_MSSV`, ví dụ `Nam_NguyenVan_20110001`. Hãy thay ví dụ bằng tên/họ/MSSV của bạn.
- Đảm bảo `index.html` nằm ở thư mục gốc của repository và GitHub Pages được bật.
